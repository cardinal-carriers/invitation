How to judge these

  • Envelope moment — this is the product's signature. Which one would you want to receive?
  • Range — it has to carry both a black-tie wedding and a Saturday-afternoon baby shower.
  • Longevity — the card art changes per event; the chrome around it shouldn't fight it.

Mixing is fine

  • e.g. 01's type with 02's layout, or 04's envelope on a light background.
  • Tell me what you like from each and I'll produce a single merged direction.

Then

  • Lock the design system and start Phase 1 (see docs/plan.md).
